# Retirement: Dv3, Dsv3, Ev3, and Esv3 Azure VMs

As part of the Microsoft Azure VM lifecycle policy, Microsoft is announcing the retirement of the Dv3, Dsv3, Ev3, and Esv3 Azure VM series in public cloud Azure regions. These VMs will enter the End-of-Life lifecycle stage and retire on November 15, 2029.

Source: [azure-updates](https://azure.microsoft.com/updates?id=572346)
