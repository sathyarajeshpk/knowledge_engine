# [Launched] Generally Available: Azure Monitor Auxiliary Logs Plan in Azure Government and China regions

The Auxiliary table plan in Azure Monitor Logs is a cost-effective option for ingesting and retaining high-volume, verbose logs used for compliance and auditing. Auxiliary Logs is now generally available in the sovereign clouds: Azure Government (Fairfax)
