# [In preview] Public Preview: Migrate from AWS FSx for Windows File Server to Azure Files with Azure Storage Mover

Azure Storage Mover now supports agentless, cloud-to-cloud migration from AWS FSx for Windows File Server (SMB) to Azure Files (SMB), in preview. You can move your Windows file shares off FSx and into Azure Files without deploying or managing a migration

Source: [azure-updates](https://azure.microsoft.com/updates?id=567979)
