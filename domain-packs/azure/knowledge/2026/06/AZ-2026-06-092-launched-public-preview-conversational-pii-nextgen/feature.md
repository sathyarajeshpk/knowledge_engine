# [Launched] Public Preview: Conversational PII NextGen Playground in Microsoft Foundry

In public preview, Microsoft Foundry now offers a Conversational PII (ConvPII) NextGen Playground with transcript input and an API Configuration Panel, enabling developers to validate PII detection across multi-speaker dialogue before integrating the API.

Source: [azure-updates](https://azure.microsoft.com/updates?id=564246)
