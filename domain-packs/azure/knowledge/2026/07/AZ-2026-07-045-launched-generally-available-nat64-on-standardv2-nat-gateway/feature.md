# [Launched] Generally Available: NAT64 on StandardV2 NAT Gateway

StandardV2 NAT Gateway now supports NAT64, enabling IPv6 workloads to communicate with IPv4-only internet destinations by translating synthesized outbound IPv6 traffic into IPv4 traffic. NAT64 relies on a DNS64-capable resolver to synthesize IPv6 addresse
