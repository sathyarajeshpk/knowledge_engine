# The redesigned Real-Time Dashboard tile editor (Preview)

Real-Time Dashboards powered by AI (Preview) The redesigned Real-Time Dashboard tile editor (Preview) is an AI-first experience where you choose a visual type and describe what you need in natural language, and Copilot generates the visualization for review without requiring KQL expertise. For more information, see Create a Real-Time Dashboard.
