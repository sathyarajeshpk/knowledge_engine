# Building a real-time weather monitoring system with AI and Fabric Eventstream

Real-time weather monitoring with Eventstream AI Skills Building a real-time weather monitoring system with AI and Fabric Eventstream walks through using Eventstream AI Skills to generate an 11-source eventstream from a single natural-language prompt that ingests real-time weather, filters for heat-stress conditions, and lands events in an Eventhouse KQL database for cross-venue KQL analysis. For more information, see Overview of Microsoft Fabric eventstreams and Eventhouse overview.
