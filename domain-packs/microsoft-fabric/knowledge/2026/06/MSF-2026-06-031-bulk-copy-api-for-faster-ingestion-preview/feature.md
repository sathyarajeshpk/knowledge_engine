# Bulk Copy API (Preview)

Bulk Copy API for faster ingestion (Preview) Bulk Copy API (Preview) writes data directly to Fabric Data Warehouse tables from application code without first staging files, replacing row-by-row INSERT statements to improve ingestion throughput. You can use it through SqlBulkCopy for C#, SQLServerBulkCopy for Java, the bcp utility, and tools such as SSIS, Azure Data Factory, and Informatica. For more information, see Ingest data into your warehouse by using BCP API (Preview).
