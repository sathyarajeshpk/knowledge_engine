# Fabric Graph (Generally Available)

Graph in Microsoft Fabric helps you model, visualize, and analyze complex relationships within your data. It's a scalable, enterprise-grade solution that turns disconnected data into AI-powered insights. By using graph, you can uncover hidden connections within your data and enhance decision-making capabilities. For more information, see Graph in Microsoft Fabric overview.
