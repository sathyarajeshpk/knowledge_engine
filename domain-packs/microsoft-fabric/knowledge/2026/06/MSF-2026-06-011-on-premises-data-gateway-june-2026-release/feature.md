# June 2026 on-premises data gateway release

On-premises data gateway June 2026 release The June 2026 on-premises data gateway release (version 3000.322) adds Windows Web Account Manager (WAM) broker authentication, updates the bundled Apache Log4j library to 2.25.4, adds consent-driven diagnostic uploads in the Dataflow Gen2 run experience, and aligns the gateway query engine with the June 2026 Power BI Desktop release. For more information, see Update an on-premises data gateway.
