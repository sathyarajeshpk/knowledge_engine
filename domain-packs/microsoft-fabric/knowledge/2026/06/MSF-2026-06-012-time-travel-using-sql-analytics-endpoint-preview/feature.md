# Time travel using the SQL analytics endpoint

Time Travel using SQL analytics endpoint (Preview) Time travel using the SQL analytics endpoint extends the Fabric Data Warehouse time travel experience to the SQL analytics endpoint so you can query Lakehouse data exactly as it looked at any prior point in time by adding OPTION (FOR TIMESTAMP AS OF '...') once at the T-SQL statement level.

Source: [fabric-whats-new-markdown](https://learn.microsoft.com/en-us/fabric/data-warehouse/time-travel)
