# Securing the Power Query connector ecosystem

Microsoft is bringing Power Query connectors in-house to secure the connector supply chain and clarify a four-stage connector lifecycle—Preview, Generally Available, Transparent Migration, and Retirement—building on recently shipped Microsoft-owned V2 connectors such as Snowflake, Google BigQuery, and Amazon Redshift. For more information, see Snowflake connector and Google BigQuery connector.
