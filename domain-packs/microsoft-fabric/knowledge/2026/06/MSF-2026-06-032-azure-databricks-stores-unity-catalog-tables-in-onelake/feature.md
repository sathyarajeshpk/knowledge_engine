# Azure Databricks can now store Unity Catalog managed tables directly in OneLake

Azure Databricks stores Unity Catalog tables in OneLake (Preview) Azure Databricks can now store Unity Catalog managed tables directly in OneLake through a Unity Catalog external location mapped to a OneLake path (Beta), and Publish to Fabric (Preview) creates Mirrored Azure Databricks Catalog items from Catalog Explorer so the tables are immediately queryable across Fabric workloads. For more information, see OneLake catalog federation in Azure Databricks and Mirroring Azure Databricks Unity Catalog.
