# The Fabric Spark Operations Skill (Preview)

Fabric Spark Operations Skill for failure diagnosis (Preview) The Fabric Spark Operations Skill (Preview) brings AI-assisted, read-only Spark diagnostics to Microsoft Fabric: describe a notebook, pipeline, or workspace in plain language and the open-source skill resolves IDs, queries the Spark monitoring APIs, and returns a severity-ranked report with root-cause explanations and fix recommendations instead of raw logs. For more information, see Apache Spark monitoring overview and Monitor Spark applications using Spark monitoring APIs.
