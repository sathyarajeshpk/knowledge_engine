# Schema compare and a built-in SQL formatter in SSMS 22.7 (Preview)

SSMS 22.7 schema compare and SQL formatter (Preview) Schema compare and a built-in SQL formatter in SSMS 22.7 (Preview) let you diff two database definitions—a connected database, SQL project, or .dacpac—and selectively apply changes, format T-SQL from the editor context menu or on save, and set SQLCMD variables in the publish dialog for SQL projects. For more information, see Schema comparison and SQL formatter.
