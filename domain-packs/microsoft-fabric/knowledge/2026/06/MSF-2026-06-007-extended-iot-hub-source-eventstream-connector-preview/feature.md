# Extended IoT Hub source Eventstream connector (Preview)

Extended Azure IoT Hub source connector (Preview) in Fabric Eventstream preserves all event metadata, including system properties (prefixed with src) and user-defined application properties, so you can join device identity with telemetry, compute ingestion latency, and route events by device. For more information, see Add Azure IoT Hub source to an eventstream.
