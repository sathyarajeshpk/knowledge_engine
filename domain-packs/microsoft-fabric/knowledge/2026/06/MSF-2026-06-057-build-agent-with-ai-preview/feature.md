# Build agent with AI (Preview)

Build Agent with AI (Preview) The Build agent with AI (Preview) feature is an AI-assisted creation experience that generates and refines Fabric Data Agent configurations through an interactive workflow, replacing manual setup with schema- and conversation-aware recommendations for agent instructions, data source guidance, and example queries; the preview focuses on SQL and Eventhouse scenarios. For more information, see Fabric data agent concepts.
