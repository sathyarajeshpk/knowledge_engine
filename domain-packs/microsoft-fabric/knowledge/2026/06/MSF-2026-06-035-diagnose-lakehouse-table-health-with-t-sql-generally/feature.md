# Diagnose Lakehouse table health with T-SQL (Generally Available)

Lakehouse table health diagnostics (Generally Available) add the built-in sys.spgettablehealthmetrics stored procedure to the SQL analytics endpoint, returning anomaly indicators and storage metrics such as small-file counts, deleted-row counts, and checkpoint versions so you can run OPTIMIZE only when needed. For more information, see Optimize Lakehouse tables based on health checks.
