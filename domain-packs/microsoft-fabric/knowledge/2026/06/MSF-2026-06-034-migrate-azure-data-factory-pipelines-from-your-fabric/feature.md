# Fabric-first Azure Data Factory migration (Preview)

Migrate Azure Data Factory pipelines from your Fabric workspace (Preview) Fabric-first Azure Data Factory migration (Preview) lets you start and complete ADF pipeline migrations without leaving Fabric: select Migrate > Data Factory, mount a read-only reference to an ADF instance, then select pipelines, auto-map supported connections, and migrate them into a named folder with triggers disabled by default. For more information, see Upgrade Azure Data Factory pipelines to Fabric Data Factory and Migration best practices for Azure Data Factory to Fabric Data Factory.
