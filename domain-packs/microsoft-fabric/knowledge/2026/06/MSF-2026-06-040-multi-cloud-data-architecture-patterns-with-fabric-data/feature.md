# Multi-cloud data architecture patterns

Multi-cloud data architecture patterns with Fabric Data Factory (Generally Available) Multi-cloud data architecture patterns show how Fabric Data Factory uses native connectors and orchestration activities such as If-Condition, Until, and ForEach with event-based triggers to coordinate workflows across Snowflake, Databricks, Google BigQuery, and Salesforce, and how OneLake shortcuts and mirroring enable zero-copy, near real-time access with Purview lineage. For more information, see Activity overview and Connector overview.
