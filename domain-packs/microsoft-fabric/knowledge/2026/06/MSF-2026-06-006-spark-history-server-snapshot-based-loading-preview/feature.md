# Spark History Server snapshot-based loading (Preview)

Snapshot-based loading for the Spark History Server (Preview) loads Spark execution metrics and logs incrementally from the backend instead of parsing the full event log upfront, so large applications that previously took up to an hour render in seconds or minutes. You can enable event log compression and rolling for Spark Streaming jobs. For more information, see Use extended Apache Spark history server to debug and diagnose Apache Spark applications.
