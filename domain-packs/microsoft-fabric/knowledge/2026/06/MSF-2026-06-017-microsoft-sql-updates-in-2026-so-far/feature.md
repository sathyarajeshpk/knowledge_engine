# A mid-year recap of Microsoft SQL updates

Highlights include regex support for large object (LOB) types, Microsoft Entra server-level logins, AI_GENERATE_EMBEDDINGS, SQL Server 2025 RTM, and SQL database in Fabric updates such as full collation support and the migration assistant.
