# Event-driven Copy job execution with Activator (Generally Available)

Event-driven Copy job execution with Fabric Activator (Generally Available) lets you invoke a Copy job directly from an Activator rule instead of a pipeline, so data movement runs when Activator detects an event such as a new file in OneLake, a table update, or a metric threshold, avoiding empty scheduled runs. For more information, see What is Copy job in Data Factory for Microsoft Fabric?
