# Pagination support for Eventstream HTTP connector (Preview)

You can add an HTTP source to an eventstream (preview) to ingest paginated REST API responses through page-based or cursor-based pagination, eliminating custom orchestration when bringing activity logs, audit records, or operational events into Eventstream.

Source: [fabric-whats-new-markdown](https://learn.microsoft.com/en-us/fabric/real-time-intelligence/event-streams/add-source-http)
