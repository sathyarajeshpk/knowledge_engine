# Built-in Fabric data protection

Built-in Fabric data protection for AI readiness Built-in Fabric data protection applies Microsoft Purview sensitivity labels, protection policies, data loss prevention (DLP), and Data Security Posture Management (DSPM) directly to lakehouses, warehouses, semantic models, and reports, and labels persist when you export to Excel, PowerPoint, PDF, or .pbix. For more information, see Information protection in Microsoft Fabric and Protection policies in Microsoft Fabric.
