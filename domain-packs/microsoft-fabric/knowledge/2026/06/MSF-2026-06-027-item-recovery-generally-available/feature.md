# Item Recovery (Generally Available)

Item Recovery in Microsoft Fabric (Generally Available) lets authorized users restore deleted items across supported workloads through the Workspace Recycle bin or REST API within a configurable retention window of up to 90 days, and admins configure tenant-wide recovery policies from the Fabric admin portal. For more information, see Retention and recovery in Fabric.
