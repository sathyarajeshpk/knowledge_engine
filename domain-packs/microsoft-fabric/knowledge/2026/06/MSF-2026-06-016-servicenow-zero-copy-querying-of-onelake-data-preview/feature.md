# ServiceNow zero-copy querying of OneLake data (Preview)

The ServiceNow OneLake connector (Preview) lets ServiceNow Workflow Data Fabric query governed OneLake data in place through the OneLake Table APIs and the Apache Iceberg REST Catalog standard, so ServiceNow workflows, analytics, and AI agents use enterprise data without ETL pipelines or copies. For more information, see OneLake overview and Iceberg table APIs overview.
