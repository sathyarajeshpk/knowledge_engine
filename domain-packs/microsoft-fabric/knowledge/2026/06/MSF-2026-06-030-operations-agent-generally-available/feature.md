# Operations agent (Generally Available)

Operations agent (Generally Available) is an autonomous agent that monitors your data with Real-Time Intelligence, reasons over your Fabric IQ ontology, and, with your approval, runs pipelines, notebooks, user data functions, and Power Automate flows, with Teams notifications, full tracing and audit, and Microsoft Agent 365 and Microsoft Entra ID governance. For more information, see Create and configure operations agents.
