# Migration Assistant direct connection (Generally Available)

Migration Assistant direct connection (Generally Available) lets you connect directly to the source warehouse for a migration to Fabric Data Warehouse. For more information, see Fabric Migration Assistant for Data Warehouse and Migrate with a direct connection.

Source: [fabric-whats-new-markdown](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Migration-Assistant-Enhancements-for-Fabric-Data-Warehouse/ba-p/5190675)
