# Create a OneDrive or SharePoint shortcut

SharePoint and OneDrive shortcuts (Generally Available) Create shortcuts to SharePoint or OneDrive locations, with support for workspace identity and service principal authentication. For more information, see Create a OneDrive or SharePoint shortcut and Workspace identity.
