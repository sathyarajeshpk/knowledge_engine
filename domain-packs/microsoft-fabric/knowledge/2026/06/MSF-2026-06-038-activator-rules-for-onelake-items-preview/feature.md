# Activator rules for OneLake items (Preview)

In the Fabric portal, you can create and manage Activator rules for OneLake items using Fabric Activator. These rules allow you to automate actions based on specific events or conditions related to OneLake items, such as when a file is created or deleted. You can also create rules based on the status of processes that interact with OneLake items, such as pipelines, Spark jobs, and notebooks. For more information, see Trigger Fabric items.

Source: [fabric-whats-new-markdown](https://learn.microsoft.com/en-us/fabric/real-time-intelligence/data-activator/activator-trigger-fabric-items)
