# Service issue communications in Fabric (Preview)

Service issue notifications and Service Health dashboard (Preview) Service issue communications in Fabric (Preview) surface service interruptions through in-product banners and optional Microsoft Teams and email notifications, and add a dedicated Service Health page in the admin portal under Help + Support so admins can track active issues and recent incidents. For more information, see Configure service interruption notifications and Track service health in Fabric.
