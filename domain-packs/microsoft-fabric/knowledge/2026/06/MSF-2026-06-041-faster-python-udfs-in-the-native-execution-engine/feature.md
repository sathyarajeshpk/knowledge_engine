# Python UDFs and complex data types in the Native Execution Engine

Faster Python UDFs in the Native Execution Engine Python UDFs and complex data types in the Native Execution Engine now run in the engine's native columnar path—covering arrays, maps, and structs—which reduces serialization round-trips and avoids fallback to row-based execution, so existing notebooks and Spark jobs benefit with no code changes once it's enabled. For more information, see Native execution engine for Fabric Data Engineering.
