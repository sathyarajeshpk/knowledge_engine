# Efficient Scaledown (Preview)

Efficient Scaledown for Spark jobs (Preview) Efficient Scaledown (Preview) decouples Spark shuffle data from executor lifetime by routing shuffle output to Azure Blob Storage, so clusters scale down faster and tolerate executor loss with no notebook or query changes. It requires the Native Execution Engine on Fabric Spark Runtime 3.5 or later. For more information, see Efficient scaledown and Native execution engine for Fabric Data Engineering.
