# Efficient Scaledown (Preview)

Efficient Scaledown for Spark jobs (Preview) Efficient Scaledown (Preview) decouples Spark shuffle data from executor lifetime by routing shuffle output to Azure Blob Storage, so clusters scale down faster and tolerate executor loss with no notebook or query changes. It combines a Remote Shuffle Manager, shuffle migration, a per-stage decision layer, and adaptive query execution (AQE) optimization. For more information, see Efficient scaledown and remote shuffle manager and Native execution engine for Fabric Data Engineering.
