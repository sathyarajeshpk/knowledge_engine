# Billing for Fabric Planning (Preview)

Billing for Fabric Planning (Preview) uses a hybrid model that combines role-based and session-based pricing for Planners, Stakeholders, and Viewers with job-based pricing for automated operations such as data sync and Planning sheet updates. A session ties a user, role, and capacity to a 30-day window, and all usage meters against the unified Fabric capacity-unit (CU) model.
