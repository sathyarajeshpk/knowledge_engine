# Live Refresh for Real-Time Dashboards (Generally Available)

Real-Time Dashboards Live Refresh (Generally Available) Live Refresh for Real-Time Dashboards (Generally Available) pushes new data to dashboard tiles as soon as it lands, replacing periodic refresh polling with always-current visualizations for operational monitoring and live analytics scenarios. For more information, see Create a Real-Time Dashboard.
