# GPU-accelerated Fabric Data Warehouse (Early Access Preview)

Fabric Data Warehouse GPU query acceleration (Preview) GPU-accelerated Fabric Data Warehouse (Early Access Preview) uses NVIDIA accelerated computing to run eligible T-SQL queries on GPUs with no query rewrites, delivering up to 7x faster performance at high concurrency across all SQL analytics endpoints and warehouses in a workspace once you enable it from workspace settings. For more information, see Query acceleration in Fabric Data Warehouse (preview).
