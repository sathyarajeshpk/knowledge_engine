# Workspace outbound access protection (OAP) for Azure and Fabric events (Preview)

Workspace outbound access protection for Azure and Fabric events (Preview) Workspace outbound access protection (OAP) for Azure and Fabric events (Preview) extends outbound network controls to cross-workspace event consumption, so Activator alerts, Eventstreams, and other consumers in a protected workspace can only receive events from other workspaces when the Real-Time Events connector is added to the workspace's data connection rules. For more information, see Private links for Azure and Fabric Events.
