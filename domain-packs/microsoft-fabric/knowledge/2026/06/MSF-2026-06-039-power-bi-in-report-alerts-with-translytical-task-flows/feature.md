# Power BI in-report alerts with translytical task flows

A translytical task flow pattern for in-report alerts uses a SQL database in Fabric to store notifications, a User Data Function to write them back, and a Lakehouse shortcut to a Direct Lake semantic model to surface them as a per-report badge and detail panel inside Power BI reports—replacing email distribution lists with in-report alerts that any author can wire up. For more information, see Set up alerts directly in Power BI reports using translytical task flows.
