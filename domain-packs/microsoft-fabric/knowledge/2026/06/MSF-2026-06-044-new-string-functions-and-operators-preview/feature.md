# New string functions and operators (Preview)

New string functions and operators (Preview) expand the Fabric Data Warehouse T‑SQL language with String matching functions including (Levenshtein distance, Jaro–Winkler distance, Levenshtein similarity, and Jaro–Winkler similarity), Concatenation ( \ \ and \ \ = ), and Unicode construction (UNISTR).
