# The KPI visualization in Real-Time Dashboards is now generally available

Real-Time Dashboard KPI visualization (Generally Available) The KPI visualization in Real-Time Dashboards is now generally available, providing at-a-glance metrics with goals, status indicators, trends, and conditional formatting. For more information, see Customize Real-Time Dashboard visuals and Apply conditional formatting in Real-Time Dashboards.
