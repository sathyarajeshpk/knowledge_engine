# IDENTITY columns

Warehouse IDENTITY columns (Generally Available) IDENTITY columns are now generally available in Fabric Data Warehouse. You can use IDENTITY_INSERT and reseed operations for migration and controlled data loads. For more information, see IDENTITY columns and Use IDENTITY columns to create surrogate keys.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/IDENTITY-columns-support-for-Identity-Insert-Generally-Available/ba-p/5361138)
