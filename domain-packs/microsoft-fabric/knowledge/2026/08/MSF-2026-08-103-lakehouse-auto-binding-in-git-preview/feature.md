# Lakehouse auto-binding in Git (Preview)

Lakehouse auto-binding in Git (Preview) resolves lakehouse references automatically as notebooks move across Git-connected workspaces, making notebooks portable across development, test, and production environments. For more information, see Notebook source control and deployment.
