# dbt Job in Fabric Data Factory (Preview)

A dbt Job in Fabric Data Factory lets you author, schedule, and monitor dbt projects natively with serverless execution, integrated testing and documentation, and governance via Entra ID and SQL security policies. For more information, see dbt job in Microsoft Fabric (preview).
