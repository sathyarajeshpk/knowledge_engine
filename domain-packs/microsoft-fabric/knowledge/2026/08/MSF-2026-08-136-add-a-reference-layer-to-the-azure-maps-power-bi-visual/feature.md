# Add a reference layer to the Azure Maps Power BI visual

Azure Maps reference layer shape-matching improvements (Generally Available) Shape matching in Azure Maps reference layers now renders faster, and interactions like filtering, cross-highlighting, and zoom respond more smoothly. No configuration change is required. For more information, see Add a reference layer to the Azure Maps Power BI visual.

Source: [powerbi-whats-new](https://learn.microsoft.com/en-us/azure/azure-maps/power-bi-visual-add-reference-layer?context=%2Fpower-bi%2Fcreate-reports%2Fcontext%2Fcontext)
