# Fabric Runtime 2.0 (Preview)

Fabric Runtime 2.0 (Preview) includes Apache Spark 4.0, Delta Lake 4.0, Java 21, Scala 2.13, and Python 3.12 on Azure Linux 3.0. For more information, see Fabric Runtime 2.0 (Preview) and Apache Spark Runtimes in Fabric.
