# Create calculated columns in Power BI Desktop

Direct Lake calculated columns (Preview) Calculated columns can be defined using DAX in web modeling and Power BI Desktop on Direct Lake on OneLake semantic models without changing storage mode. Columns are evaluated at query time and support user-context functions such as USERCULTURE(). For more information, see Create calculated columns in Power BI Desktop. ✔️

Source: [powerbi-whats-new](https://learn.microsoft.com/en-us/power-bi/transform-model/desktop-calculated-columns)
