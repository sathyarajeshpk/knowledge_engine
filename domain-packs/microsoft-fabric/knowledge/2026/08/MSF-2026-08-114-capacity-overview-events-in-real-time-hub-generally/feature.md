# Capacity Overview Events in Real-Time Hub (Generally Available)

Capacity Overview Events in Real-Time Hub (Generally Available) stream capacity summary and state signals so you can monitor utilization and health, detect throttling or lifecycle changes, and trigger alerts or automated actions. For more information, see Introduction to Azure and Fabric events and Explore Fabric capacity overview events.
