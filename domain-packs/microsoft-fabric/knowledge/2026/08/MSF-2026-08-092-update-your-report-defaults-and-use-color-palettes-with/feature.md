# Update your report defaults and use color palettes with modern visual defaults (Preview)

Modern Visual Defaults now includes a Customize current theme experience in the Format pane. Adjust report-wide defaults for visuals, choose color palettes, and control visual elements like background, border, header icons, tooltips, and shadow across your entire report. Update page size, background color, and wallpaper across all pages at once. When finished, export your custom theme for use in other reports or add it to organizational themes. For more information, see Visual defaults in Power BI reports. ✔️
