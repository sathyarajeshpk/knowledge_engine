# Visual defaults in Power BI reports

Modern visual defaults and customize themes formatting panes (Generally Available) New reports start with the Fluent 2 base theme. Use the Theme pane to set a base theme, adjust color palettes, change text styles, set visual and page properties, and import or export custom themes in Desktop or on the web. Font overrides are removed from the base theme so the Text section now applies consistently across all visuals. For more information, see Visual defaults in Power BI reports.

Source: [powerbi-whats-new-markdown](https://learn.microsoft.com/en-us/power-bi/create-reports/power-bi-reports-visual-defaults)
