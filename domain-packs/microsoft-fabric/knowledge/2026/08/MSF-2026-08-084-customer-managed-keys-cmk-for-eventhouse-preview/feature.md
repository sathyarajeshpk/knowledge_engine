# Customer Managed Keys (CMK) for Eventhouse (Preview)

Customer Managed Keys (CMK) for Eventhouse (Preview) lets you bring your own Azure Key Vault key to encrypt Eventhouse data at rest, meeting strict regulatory requirements while keeping you in control of the key lifecycle. For more information, see Data Encryption in Fabric Eventhouse (Preview).
