# Customize x-axis and y-axis properties

Outer padding for bar, column, line, ribbon, and waterfall charts (Generally Available) An Outer padding setting under Layout controls the space between the plot area edges and the first and last categories. Set to 0% to fill the plot area; combine with Space between categories at 0% to fully fill. For more information, see Customize x-axis and y-axis properties.

Source: [powerbi-whats-new](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-customize-x-axis-and-y-axis)
