# Resource Instance Rules for OneLake (Preview)

Resource Instance Rules for OneLake (Preview) let workspace admins allow inbound access to OneLake from explicitly trusted Azure resource instances by identity, complementing Private Link and IP firewall rules for service-to-service scenarios without requiring IP allow lists or private networking. For more information, see Manage inbound access to OneLake with Resource Instance Rules (preview).
