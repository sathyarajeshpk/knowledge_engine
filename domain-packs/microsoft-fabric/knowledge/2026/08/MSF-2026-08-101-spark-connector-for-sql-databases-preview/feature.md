# Spark Connector for SQL databases

Spark Connector for SQL databases (Preview) Spark Connector for SQL databases lets Spark read and write to Azure SQL Database, Azure SQL Managed Instance, SQL Server on Azure VM, and Fabric SQL databases with built-in authentication and PySpark support. For more information, see Spark connector for SQL databases (Preview).
