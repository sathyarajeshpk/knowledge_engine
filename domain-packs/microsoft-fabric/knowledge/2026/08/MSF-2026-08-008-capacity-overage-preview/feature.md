# Capacity overage (Preview)

Capacity overage (Preview) is an opt-in capability that automatically bills for excess capacity usage during compute spikes instead of throttling, with admin-configurable limits per 24-hour window. For more information, see Capacity overage (preview) in Microsoft Fabric.
