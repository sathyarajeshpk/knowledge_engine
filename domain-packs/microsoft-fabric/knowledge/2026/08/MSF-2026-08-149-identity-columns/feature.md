# IDENTITY columns

Warehouse IDENTITY columns (Generally available) IDENTITY columns automatically produce unique values for each new row, eliminating the need for manual key assignments and eliminating the risk of key duplication and key integrity issues. For more information and to get started, see IDENTITY columns and Use IDENTITY columns to create surrogate keys. You can also learn how to Migrate to IDENTITY columns in Fabric Data Warehouse.

Source: [fabric-whats-new](https://learn.microsoft.com/en-us/fabric/data-warehouse/identity)
