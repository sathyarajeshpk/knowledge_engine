# Azure Monitor to Fabric Eventhouse (Preview)

Azure Monitor to Fabric Eventhouse (Preview) lets you route VM telemetry via Azure Monitor Agent and Data Collection Rules into Eventhouse for schema-managed ingestion, ad hoc queries, time-series analytics, and activation. For more information, see Send virtual machine client data to Fabric and Azure Data Explorer (Preview).

Source: [fabric-whats-new-markdown](https://blog.fabric.microsoft.com/blog/azure-monitor-to-fabric-eventhouse-preview)
