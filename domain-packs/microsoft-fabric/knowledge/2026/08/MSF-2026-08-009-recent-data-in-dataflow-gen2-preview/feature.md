# Recent data in Dataflow Gen2 (Preview)

Recent data in Dataflow Gen2 (Preview) provides quick access to your most frequently used data items in the Power Query ribbon and Modern Get Data, letting you jump directly to recently used tables, files, folders, and databases without navigation. For more information, see Get data experience and What is Dataflow Gen2?
