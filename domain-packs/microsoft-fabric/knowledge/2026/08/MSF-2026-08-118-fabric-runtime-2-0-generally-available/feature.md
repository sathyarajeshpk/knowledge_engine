# Fabric Runtime 2.0 (Generally Available)

Fabric Runtime 2.0 (Generally Available) includes Apache Spark 4.1, Delta Lake 4.2, Python 3.13, Java 21, Scala 2.13, and Azure Linux 3.0, and remains opt-in until its planned default rollout. For more information, see Runtime 2.0 in Fabric.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Fabric-Runtime-2-0-Generally-Available/ba-p/5326359)
