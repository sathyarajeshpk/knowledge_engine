# Migration Assistant to SQL database (preview)

The new Migration Assistant for SQL database simplifies moving SQL Server on-premises workloads into Fabric. Designed for SQL developers, it imports schema via DACPACs, identifies compatibility issues, and provides clear, actionable guidance before migration. For more information, see Fabric Migration Assistant for SQL database (Preview) and Introducing the Migration Assistant to SQL database in Fabric (preview).
