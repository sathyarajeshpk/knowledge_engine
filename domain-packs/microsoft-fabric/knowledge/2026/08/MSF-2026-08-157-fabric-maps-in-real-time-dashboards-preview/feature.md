# Fabric Maps in Real-Time Dashboards (Preview)

Fabric Maps in Real-Time Dashboards (Preview) lets you add a published Fabric Map as a dashboard tile while keeping the map's layers, filters, and styling in the map item. For more information, see Add a Fabric Maps tile.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Bring-Fabric-Maps-into-Real-Time-Dashboards-Preview/ba-p/5360916)
