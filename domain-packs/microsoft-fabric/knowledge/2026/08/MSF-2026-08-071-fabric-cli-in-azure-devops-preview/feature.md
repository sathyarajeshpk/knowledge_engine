# Fabric CLI in Azure DevOps (Preview)

The Fabric CLI in Azure DevOps (Preview) provides the Fabric CLI (fab) as a built-in Azure DevOps pipeline task for automating workspace and item management without manual tool installation. Get started with the Fabric CLI (generally available) at https://aka.ms/FabCLI.
