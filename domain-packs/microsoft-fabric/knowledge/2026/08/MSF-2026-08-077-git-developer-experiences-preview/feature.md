# Git developer experiences (Preview)

New Git developer experiences (Preview) add branched workspaces for formal source-to-feature workspace relationships, selective branching to branch out with only the items you need, and the ability to Compare Code Changes for rich diff review before committing or syncing.

Source: [fabric-whats-new-markdown](https://blog.fabric.microsoft.com/blog/introducing-new-git-developer-experiences-in-microsoft-fabric-preview?ft=All)
