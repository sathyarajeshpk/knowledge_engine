# Report page tab navigation improvements (Generally Available)

When dragging a page tab to reorder it, tabs continue to scroll until you reach the desired position, making it easier to move pages from the end to the beginning of your report. Arrow buttons for paging through tabs are more precise, ensuring you see each report page tab as you navigate. For more information, see Report view in Power BI Desktop.

Source: [powerbi-whats-new-markdown](https://learn.microsoft.com/en-us/power-bi/create-reports/desktop-report-view)
