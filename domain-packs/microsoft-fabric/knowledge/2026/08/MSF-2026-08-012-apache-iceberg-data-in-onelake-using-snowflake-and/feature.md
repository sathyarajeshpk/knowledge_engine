# Apache Iceberg data in OneLake using Snowflake and shortcuts (Preview)

You can now consume Apache Iceberg-formatted data across Microsoft Fabric with no data movement or duplication, plus Snowflake added the ability to write Iceberg tables directly to OneLake. For more information, see Use Apache Iceberg tables with OneLake.
