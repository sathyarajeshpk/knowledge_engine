# Export data from a Power BI visualization

Export data to Excel in the Power BI mobile app Data from report visuals can be exported to Excel directly from the Power BI mobile app for iOS and Android, via focus mode or the visual's More options (…) menu. The export reflects current filters, slicers, drill state, and row-level security. For more information, see Export data from a Power BI visualization.

Source: [powerbi-whats-new](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-export-data)
