# Data clustering in Fabric Data Warehouse

Warehouse data clustering (Preview) Data clustering is a technique used to organize and store data based on similarity. Data clustering improves query performance and reduces compute and storage access costs for queries by grouping similar records together. For more information and to get started, see Data clustering in Fabric Data Warehouse and Use data clustering in Fabric Data Warehouse (Preview).
