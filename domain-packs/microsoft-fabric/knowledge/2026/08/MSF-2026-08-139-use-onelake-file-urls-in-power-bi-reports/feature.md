# Use OneLake file URLs in Power BI reports

OneLake file URLs for report visuals and maps (Generally Available) Image files stored in OneLake can be used as image sources in the image visual, table and matrix cells, the card visual, button and list slicers, and custom icons in the Icons cell element. Power BI authenticates on the viewer's behalf. Reference layer maps and shape map files can also be linked from OneLake URLs. For more information, see Use OneLake file URLs in Power BI reports, Display images in a table, matrix, or slicer, and Image visual in Power BI.

Source: [powerbi-whats-new](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-onelake-files)
