# Fabric Core MCP Server (Preview)

Fabric Core MCP Server (Preview) is a remote, cloud-hosted Model Context Protocol server that lets AI agents perform real, authenticated operations against Fabric workspaces, items, search, permissions, connections, and OneLake through Microsoft Entra ID with full audit logging, with no local install. For more information, see Get started with Fabric Core MCP Server.
