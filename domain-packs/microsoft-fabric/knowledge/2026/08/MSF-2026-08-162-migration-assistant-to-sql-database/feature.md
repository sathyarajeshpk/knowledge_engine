# Migration Assistant to SQL database

Migration Assistant to SQL database (Generally Available) Migration Assistant to SQL database is generally available and lets you validate a source DACPAC for compatibility before provisioning a SQL database in Fabric. For more information, see Fabric Migration Assistant for SQL database.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Fabric-Migration-Assistant-for-SQL-database-Generally-Available/ba-p/5363606)
