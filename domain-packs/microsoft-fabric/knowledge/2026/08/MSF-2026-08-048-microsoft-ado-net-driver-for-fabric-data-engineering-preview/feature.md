# Microsoft ADO.NET Driver for Fabric Data Engineering (Preview)

The Microsoft ADO.NET Driver for Fabric Data Engineering (Preview) lets .NET applications connect to Spark SQL in Fabric using standard ADO.NET patterns with Microsoft Entra ID authentication, connection pooling, and async prefetch via Livy APIs. For more information, see Microsoft ADO.NET driver for Microsoft Fabric Data Engineering (preview).
