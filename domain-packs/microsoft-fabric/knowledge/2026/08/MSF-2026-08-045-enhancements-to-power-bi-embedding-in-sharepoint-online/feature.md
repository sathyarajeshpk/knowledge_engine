# Add a Power BI report to SharePoint Online

Enhancements to Power BI embedding in SharePoint Online A new UI lets you browse and select a workspace directly, instead of copying and pasting a URL. You can also embed a single visual using the Embed a single visual toggle. For more information, see Add a Power BI report to SharePoint Online.
