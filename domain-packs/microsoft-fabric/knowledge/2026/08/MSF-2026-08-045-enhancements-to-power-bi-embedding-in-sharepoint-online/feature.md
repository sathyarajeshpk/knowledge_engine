# Add a Power BI report to SharePoint Online

Enhancements to Power BI embedding in SharePoint Online A new UI lets you directly select the workspace you want to embed in SharePoint instead of copying and pasting the full URL. You can now embed a visual by selecting the Embed a single visual toggle. For more information, see Add a Power BI report to SharePoint Online.

Source: [powerbi-whats-new-markdown](https://learn.microsoft.com/en-us/power-bi/collaborate-share/service-embed-report-spo)
