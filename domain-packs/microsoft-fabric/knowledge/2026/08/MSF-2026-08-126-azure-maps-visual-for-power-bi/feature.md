# Azure Maps visual for Power BI

Azure Maps loads filtered selection and autozoom (Generally Available) When you filter to a smaller data set, the Azure Maps visual reloads to include data points that were outside the initial 30,000-point limit. The map also automatically zooms to fit the currently filtered area. For more information, see Azure Maps visual for Power BI.

Source: [powerbi-whats-new](https://learn.microsoft.com/en-us/azure/azure-maps/power-bi-visual-getting-started?context=%2Fpower-bi%2Fcreate-reports%2Fcontext%2Fcontext)
