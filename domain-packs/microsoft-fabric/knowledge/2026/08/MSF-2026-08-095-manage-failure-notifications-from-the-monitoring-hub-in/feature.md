# Manage failure notifications from the monitoring hub in Fabric (Preview)

The Schedule failures page in the Fabric monitoring hub (Preview) lists every scheduled item with failure notifications configured and lets you add, edit, or remove recipients for any item from one place, without opening each item individually. For more information, see Schedule failures (preview) and Receive notifications for failed scheduled jobs.
