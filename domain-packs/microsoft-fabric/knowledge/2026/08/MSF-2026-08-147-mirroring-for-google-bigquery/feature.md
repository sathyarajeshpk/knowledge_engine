# Mirroring for Google BigQuery

Mirroring for Google BigQuery (Generally Available) Mirroring for Google BigQuery is now generally available with full production support. Continuously replicate BigQuery tables into OneLake as open Delta tables — no ETL pipelines, no data movement, and no refresh management — with automatic schema evolution, Direct Lake integration for Power BI, and zero Fabric replication compute or network ingress cost. For more information, see Mirrored databases from Google BigQuery and Tutorial: Set up mirroring for Google BigQuery.

Source: [fabric-whats-new](https://learn.microsoft.com/en-us/fabric/mirroring/google-bigquery)
