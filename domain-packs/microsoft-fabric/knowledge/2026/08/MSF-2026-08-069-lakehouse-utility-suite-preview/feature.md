# Lakehouse utility suite (Preview)

The Lakehouse Utility Suite now includes the Lakehouse maintenance activity (Preview), to automate routine Lakehouse upkeep tasks, and the Refresh SQL endpoint activity (Preview), to refresh the Lakehouse SQL analytics endpoint on demand or on a schedule within Fabric pipelines.
