# Capacity Metrics and Query Insights

Warehouse consumption attribution Capacity Metrics and Query Insights help you estimate which queries, users, and workloads contributed to warehouse capacity consumption by allocating warehouse-level capacity units in proportion to query-level vCore seconds. For more information, see Observe Fabric Data Warehouse utilization trends and Billing and utilization reporting.
