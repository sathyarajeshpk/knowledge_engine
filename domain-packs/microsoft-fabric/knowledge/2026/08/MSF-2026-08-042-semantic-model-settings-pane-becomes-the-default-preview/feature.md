# Edit semantic models in the Power BI Service

Semantic model settings pane becomes the default (Preview) Starting in August, semantic model settings open in the new settings pane instead of the full settings page. The pane opens beside your content, so you can update refresh schedules, credentials, and other options without leaving your workspace. For more information, see Edit semantic models in the Power BI Service. ✔️
