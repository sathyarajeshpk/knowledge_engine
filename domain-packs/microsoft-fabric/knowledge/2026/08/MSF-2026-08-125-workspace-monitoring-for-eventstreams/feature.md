# Workspace monitoring for Eventstreams

Eventstream workspace monitoring with per-eventstream control (Preview) Workspace monitoring for Eventstreams lets you choose which eventstreams emit performance, error, and node-health data to three KQL tables in the workspace monitoring Eventhouse. For more information, see Eventstream monitoring in Workspace Monitoring and Workspace Monitoring overview.
