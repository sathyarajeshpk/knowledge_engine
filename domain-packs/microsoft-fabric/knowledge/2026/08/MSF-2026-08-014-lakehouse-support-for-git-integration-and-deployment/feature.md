# Lakehouse now integrates with the lifecycle management capabilities in Microsoft Fabric

Lakehouse support for git integration and deployment pipelines (Preview) The Lakehouse now integrates with the lifecycle management capabilities in Microsoft Fabric, providing a standardized collaboration between all development team members throughout the product's life. Lakehouse git integration and deployment pipelines facilitates an effective product versioning and release process by continuously delivering features and bug fixes into multiple environments.

Source: [fabric-whats-new-markdown](https://blog.fabric.microsoft.com/blog/microsoft-fabric-november-2023-update)
