# ML model endpoints (Preview)

ML models in Fabric can now serve real-time predictions from secure, scalable, and easy-to-use online endpoints. In addition to batch predictions in Spark, you can use endpoints to bring ML model predictions to other Fabric solutions and custom applications. For more information, see Automated ML in Fabric and Model endpoints in Fabric.

Source: [fabric-whats-new-markdown](https://blog.fabric.microsoft.com/blog/serve-real-time-predictions-seamlessly-with-ml-model-endpoints?ft=All)
