# OpenAI plugins for Eventhouse (Preview)

You can now use two powerful AI plugins for Eventhouse: AI Embed Text Plugin and AI Chat Completion Prompt Plugin. Connect Eventhouse data to OpenAI-powered applications for advanced analytics and AI scenarios. For more information, see aiembedtext (preview) and aichatcompletion (preview).
