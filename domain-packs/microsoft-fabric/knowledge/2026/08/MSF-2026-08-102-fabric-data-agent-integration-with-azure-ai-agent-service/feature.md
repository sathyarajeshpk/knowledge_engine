# Fabric Data Agent integration with Azure AI Agent Service (Preview)

We're excited to launch the integration of data agents in Fabric with Azure AI Agent Service from Microsoft Foundry. To get started, see Consume a Fabric Data Agent in Microsoft Copilot Studio (preview). The Fabric data agent SDK is also available in preview.
