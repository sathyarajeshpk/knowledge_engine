# Create an app connected to a semantic model

Updates to required semantic model permissions for Fabric Apps By the end of August, Fabric App consumers need only Read permission on the underlying semantic model, instead of Build permission. App authors still require Build permission. For more information, see Create an app connected to a semantic model.

Source: [powerbi-whats-new](https://learn.microsoft.com/en-us/fabric/apps/data-apps-template)
