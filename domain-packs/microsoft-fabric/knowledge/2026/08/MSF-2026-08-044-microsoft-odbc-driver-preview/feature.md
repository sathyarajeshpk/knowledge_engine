# Microsoft ODBC Driver (Preview)

The Microsoft ODBC Driver for Fabric Data Engineering (Preview) enables .NET, Python, and other ODBC-compatible applications and BI tools to connect to Spark SQL in Fabric through Livy APIs with Microsoft Entra ID authentication, session reuse, and async prefetch. For more information, see Microsoft ODBC driver for Microsoft Fabric Data Engineering (Preview).
