# Google Lakehouse Runtime Catalog mirroring (Preview)

Google Lakehouse Runtime Catalog mirroring (Preview) brings Google-managed Iceberg catalog metadata into OneLake without copying data, so you can use the tables across Fabric workloads. For more information, see Google Lakehouse Runtime Catalog mirroring.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Bring-your-Google-Lakehouse-Runtime-Catalog-data-to-OneLake/ba-p/5360492)
