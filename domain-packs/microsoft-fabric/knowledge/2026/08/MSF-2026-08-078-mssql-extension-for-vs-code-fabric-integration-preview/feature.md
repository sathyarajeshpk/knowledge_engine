# MSSQL extension for VS Code Fabric integration (Preview)

MSSQL extension for VS Code Fabric integration (Preview) adds support for connecting, running queries, and managing objects in SQL databases in Fabric directly from Visual Studio Code. Download the extension at MSSQL extension at marketplace.visualstudio.com.

Source: [fabric-whats-new-markdown](https://blog.fabric.microsoft.com/blog/mssql-extension-for-vs-code-fabric-integration-public-preview)
