# Fabric Migration Assistant for SQL database

Migration Assistant to SQL database The Migration Assistant for SQL database simplifies moving SQL Server on-premises workloads into Fabric. Designed for SQL developers, it imports schema via DACPACs, identifies compatibility issues, and provides clear, actionable guidance before migration. For more information, see Fabric Migration Assistant for SQL database.

Source: [fabric-whats-new](https://learn.microsoft.com/en-us/fabric/database/sql/migration-assistant)
