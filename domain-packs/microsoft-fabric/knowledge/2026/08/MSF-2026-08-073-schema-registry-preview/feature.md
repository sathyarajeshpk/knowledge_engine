# Schema Registry (Preview)

Event Schema Registry (preview) provides a contract-based way to define and validate event schemas in Fabric Eventstreams for type-safe, reliable real-time pipelines. For more information, see Schema Registry in Fabric Real-Time Intelligence (preview).

Source: [fabric-whats-new-markdown](https://blog.fabric.microsoft.com/blog/schema-registry-creating-type-safe-pipelines-using-schemas-and-eventstreams-preview)
