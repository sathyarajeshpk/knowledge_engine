# TMDL View on the web

Developers can script, modify, and apply changes to model objects directly in a code editor using Tabular Model Definition Language without switching to Desktop or downloading model files. Provides code-level visibility into semantic model metadata for bulk edits, automation, and reusable definitions. For more information, see Use Tabular Model Definition Language view in Power BI Desktop.

Source: [powerbi-whats-new-markdown](https://learn.microsoft.com/en-us/power-bi/transform-model/desktop-tmdl-view)
