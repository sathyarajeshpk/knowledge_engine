# use T-SQL predicate expressions to filter which events are captured in your SQL audit logs

SQL audit logs predicate filtering You can use T-SQL predicate expressions to filter which events are captured in your SQL audit logs of Fabric Data Warehouse and SQL analytics endpoint. For more information, see SQL audit logs in Fabric Data Warehouse.
