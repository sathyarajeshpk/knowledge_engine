# preview of prebuilt Foundry Tools in Fabric

Prebuilt Foundry Tools in Fabric preview The preview of prebuilt Foundry Tools in Fabric is an integration with Foundry Tools, formerly known as Azure AI services. Foundry Tools (preview) allow for easy enhancement of data with prebuilt AI models without any prerequisites. Currently, prebuilt Foundry Tools are in preview and include support for the Microsoft Azure OpenAI Service, Azure Language in Foundry Tools, and Azure Translator in Foundry Tools.

Source: [fabric-whats-new-markdown](https://blog.fabric.microsoft.com/blog/prebuilt-azure-ai-services-in-fabric-2)
