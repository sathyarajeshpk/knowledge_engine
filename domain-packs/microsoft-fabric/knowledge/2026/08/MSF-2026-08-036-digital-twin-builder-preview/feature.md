# Digital twin builder (Preview)

Digital twin builder (preview) is an item within the Real-Time Intelligence workload. Digital twins create data-driven, real-time representations of entities. It's a data modeling item that creates digital representations of real-world environments, to optimize physical operations using data. For more information, see What is digital twin builder (preview)?
