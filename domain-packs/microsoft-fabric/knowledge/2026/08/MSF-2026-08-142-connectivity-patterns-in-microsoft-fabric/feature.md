# Connectivity patterns in Microsoft Fabric

Connectivity patterns for data integration workloads Connectivity patterns in Microsoft Fabric compare public endpoints, managed virtual networks, virtual network data gateways, and on-premises data gateways for data integration workloads. For more information, see Managed virtual networks in Fabric and Virtual network data gateways.
