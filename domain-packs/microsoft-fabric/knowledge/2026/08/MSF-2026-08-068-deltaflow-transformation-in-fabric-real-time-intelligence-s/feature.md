# DeltaFlow transformation in Fabric Real-Time Intelligence's Eventstream (preview)

DeltaFlow is a capability in Fabric Eventstream that transforms raw Change Data Capture (CDC) events into a flattened, analytics-ready format. Instead of working with deeply nested Debezium JSON payloads, DeltaFlow produces tabular rows that closely mirror the structure of the source database tables, enriched with metadata columns that describe each change. Eventstream supports DeltaFlow transformations, which are currently in preview. For more information, see DeltaFlow output transformation (preview) and Blog: Business Events in Microsoft Fabric (Preview).
