# Scheduled User Data Functions (Preview)

Scheduled User Data Functions (Preview) run parameterized business logic on a recurring cadence through the Fabric job scheduler, with execution history available in the monitoring hub. For more information, see User Data Functions overview and Schedule a User Data Function.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Automate-recurring-business-logic-with-scheduled-User-Data/ba-p/5341912)
