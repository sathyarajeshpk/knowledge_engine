# Fabric Capacity overview events in Real-Time Hub (Preview)

Fabric Capacity overview events in Real-Time Hub (Preview) adds real-time capacity summary and state events so you monitor health, detect throttling, and trigger actions using Activator, Eventstream, and dashboards.
