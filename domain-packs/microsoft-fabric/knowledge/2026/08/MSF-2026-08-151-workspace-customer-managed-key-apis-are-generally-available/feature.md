# Workspace customer-managed key APIs are generally available

Workspace customer-managed key APIs (Generally Available) Workspace customer-managed key APIs are generally available, so administrators can automate workspace encryption-key assignment and removal. For more information, see Customer-managed keys for Fabric workspaces and Assign workspace encryption.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Customer-Managed-Key-CMK-APIs-for-Microsoft-Fabric-Workspaces/ba-p/5360035)
