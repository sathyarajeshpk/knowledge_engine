# Continuous ingestion from Azure Storage to Eventhouse (Preview)

You can now use continuous ingestion from Azure Storage to Eventhouse (preview) to automatically and efficiently ingest data from Azure Storage into Eventhouse. For more information, see Get data from Azure Storage.
