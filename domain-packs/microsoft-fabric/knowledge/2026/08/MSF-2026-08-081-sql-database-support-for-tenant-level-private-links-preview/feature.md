# tenant and workspace-level private links

SQL database support for private links (Preview) You can use tenant and workspace-level private links to provide secure access for data traffic in Microsoft Fabric, including SQL database. For SQL database, workspace-level private links are in preview. For more information, see Set up and use private links.

Source: [fabric-whats-new-markdown](https://learn.microsoft.com/en-us/fabric/security/security-private-links-overview)
