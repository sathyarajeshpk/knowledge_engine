# tenant level private links

SQL database support for Tenant level private links (Preview) You can use tenant level private links to provide secure access for data traffic in Microsoft Fabric, including SQL database (in preview). For more information, see Set up and use tenant-level private links and Blog: Tenant Level Private Link (Preview).

Source: [fabric-whats-new-markdown](https://learn.microsoft.com/en-us/fabric/security/security-private-links-overview)
