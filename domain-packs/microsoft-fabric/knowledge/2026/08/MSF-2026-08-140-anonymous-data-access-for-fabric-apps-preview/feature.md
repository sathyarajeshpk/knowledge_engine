# Anonymous data access for Fabric Apps (Preview)

Anonymous data access for Fabric Apps (Preview) lets an app expose selected entity operations to unauthenticated visitors while tenant settings and data-model roles limit access. For more information, see Anonymous data access.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Introducing-anonymous-data-access-for-Fabric-Apps-Preview/ba-p/5361116)
