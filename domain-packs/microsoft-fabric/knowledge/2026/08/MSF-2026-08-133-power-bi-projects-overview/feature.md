# Power BI Projects overview

Faster PBIP development with instant reloads and VS Code integration Power BI Desktop detects external changes to PBIP project files and prompts you to apply them with a single click. A built-in entry point opens the project directly in Visual Studio Code. For more information, see Power BI Projects overview.

Source: [powerbi-whats-new](https://learn.microsoft.com/en-us/power-bi/developer/projects/projects-overview)
