# Item Recovery is enabled by default

Item Recovery enabled by default Item Recovery is enabled by default beginning August 16, 2026, for tenants without an explicit setting, with a three-day retention window; existing settings remain unchanged, and admins can set retention from 3 to 90 days or disable recovery. For more information, see Retention and recovery in Fabric and OneLake consumption.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Enabling-Item-Recovery-by-default-in-Microsoft-Fabric/ba-p/5323843)
