# Fabric Data Agent integration with Microsoft Copilot Studio

Fabric Data Agent integration with Microsoft Copilot Studio (Generally Available) Fabric Data Agent integration with Microsoft Copilot Studio adds a Fabric data agent to a Copilot Studio agent as a Fabric IQ Data MCP tool while retaining source permissions.
