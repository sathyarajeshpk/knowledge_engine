# August 2026 on-premises data gateway release

On-premises data gateway August 2026 release The August 2026 on-premises data gateway release updates the gateway to version 3000.330 and aligns its query execution with the August 2026 Power BI Desktop release. For more information, see Update an on-premises data gateway.
