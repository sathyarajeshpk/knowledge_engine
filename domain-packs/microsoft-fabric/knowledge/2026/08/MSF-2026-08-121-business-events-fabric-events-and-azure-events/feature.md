# Business Events, Fabric Events, and Azure Events

Choose an event pillar The easiest way to understand Fabric eventing is not to start with the consumer. Start with the publisher. Who is saying that something happened? That answer determines which Fabric event pillar you use. Business Events, Fabric Events, and Azure Events serve different publishers and consumers: your workloads publish Business Events, Fabric publishes platform events, and Azure Storage publishes Azure Events. For more information, see Business events overview and Fabric events overview.
