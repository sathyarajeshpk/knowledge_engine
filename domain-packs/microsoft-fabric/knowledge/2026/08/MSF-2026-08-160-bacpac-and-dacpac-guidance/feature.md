# BACPAC and DACPAC guidance

BACPAC and DACPAC guidance explains that BACPAC files provide schema and data portability for Azure SQL Database, while DACPAC files support schema deployments and can optionally include data for SQL database in Fabric. For more information, see SqlPackage for SQL database in Microsoft Fabric.

Source: [fabric-whats-new](https://devblogs.microsoft.com/azure-sql/bacpac-and-dacpac-the-similarities-and-differences)
