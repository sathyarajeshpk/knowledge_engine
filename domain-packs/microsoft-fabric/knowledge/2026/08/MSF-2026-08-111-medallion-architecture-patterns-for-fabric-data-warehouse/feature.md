# Medallion architecture patterns for Fabric Data Warehouse

Medallion patterns for Fabric Data Warehouse Medallion architecture patterns for Fabric Data Warehouse compare an all-in-one warehouse approach for SQL-focused, structured workloads with a Lakehouse and warehouse hybrid for workloads that need Spark or unstructured data processing. For more information, see Fabric Data Warehouse and OneLake overview.
