# Zero-copy access to OneLake data in Azure Databricks (Preview)

OneLake catalog federation in Azure Databricks (Preview) enables Unity Catalog to query Fabric data stored in OneLake without copying, keeping OneLake as the source of truth while allowing Databricks compute to analyze tables through synchronized metadata and zero-copy data access. For more information, see Enable OneLake catalog federation.
