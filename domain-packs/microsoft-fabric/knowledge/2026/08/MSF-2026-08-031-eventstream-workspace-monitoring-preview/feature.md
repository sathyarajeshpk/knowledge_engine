# Workspace monitoring for Eventstreams (Preview)

Eventstream workspace monitoring (Preview) Workspace monitoring for Eventstreams (Preview) automatically creates three Eventhouse tables (EventStreamNodeStatus, EventStreamMetrics, EventStreamErrorMetrics) for per-minute data volume, watermark delay, backlog, and error counts queryable with KQL. Existing Eventstreams need a republish to start emitting telemetry. For more information, see Eventstreams and Workspace monitoring.
