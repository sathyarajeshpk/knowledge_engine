# Data replication from Lakehouse with Delta Change Feed (Preview)

The Fabric Lakehouse Table connector provides changed data from a Fabric Lakehouse via Delta Change Data Feed (CDF), to supported destinations. For more information, see Data Replication from Fabric Lakehouse with Delta Change Data Feed (Preview).
