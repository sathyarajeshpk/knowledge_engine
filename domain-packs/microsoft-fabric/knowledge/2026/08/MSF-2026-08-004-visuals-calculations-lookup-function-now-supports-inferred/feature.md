# Visuals calculations LOOKUP function now supports INFERRED mode

The LOOKUP function in visual calculations now accepts an optional AssociatedColumnsBehavior parameter with EXPLICIT (default) and INFERRED values. When using INFERRED, the engine automatically identifies which axis columns are functionally determined by the coordinates you supply and fills them in before evaluating the lookup. For more information, see Using visual calculations.
