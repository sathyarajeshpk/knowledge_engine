# Create support tickets from within Microsoft Fabric (Generally Available)

Ticket creation from within Microsoft Fabric (Generally Available) lets eligible Fabric and Power BI users open support cases from the Help Pane, which collects session metadata such as tenant location and item identifiers and routes them to support engineers without leaving Fabric. Admins control availability through the Publish "Get Help" information tenant setting. For more information, see Create a Fabric and Power BI support ticket and Publish "Get Help" information.
