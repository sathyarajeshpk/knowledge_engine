# Custom authorization for API for GraphQL (Preview)

Authorizer User Data Functions for API for GraphQL (Preview) let you attach a User Data Function that runs before each GraphQL operation and evaluates request context such as tenant ID, role, or token claims to allow, restrict, or deny access based on your own policy logic. For more information, see What is Microsoft Fabric API for GraphQL? and Create a Fabric User data functions item.
