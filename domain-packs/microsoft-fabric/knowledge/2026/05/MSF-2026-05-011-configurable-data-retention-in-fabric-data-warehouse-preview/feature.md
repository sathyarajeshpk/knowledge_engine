# Configurable Data Retention in Fabric Data Warehouse (Preview)

Configurable data retention (Preview) in Fabric Data Warehouse lets you set the data history retention window for a warehouse between 1 and 120 days with a single T-SQL command. This governs time travel, point-in-time clones, restore points, and warehouse snapshots. For more information, see Data retention in Fabric Data Warehouse (Preview).
