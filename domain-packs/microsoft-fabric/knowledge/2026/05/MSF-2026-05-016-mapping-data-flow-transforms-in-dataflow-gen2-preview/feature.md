# Mapping data flow transforms in Dataflow Gen2 (Preview)

Mapping Data Flow Transforms in Dataflow Gen2 (Preview) Mapping data flow transforms in Dataflow Gen2 (Preview) introduces Spark-based transformation capabilities directly in the Dataflow Gen2 creation experience, enabling large-scale data transformations with Spark compute and migration of mapping data flows to Fabric.
