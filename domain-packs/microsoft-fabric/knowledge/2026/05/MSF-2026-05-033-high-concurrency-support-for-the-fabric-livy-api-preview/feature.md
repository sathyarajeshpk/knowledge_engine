# High Concurrency Support for the Fabric Livy API (Preview)

High Concurrency (HC) sessions for the Fabric Livy API (Preview) let multiple Spark workloads share a single managed Spark session with isolated REPLs, server-side session packing via sessionTag, parallel statement execution, and built-in surfacing in the Monitoring Hub. For more information, see High concurrency support in the Fabric Livy API and Get started with the Livy API for Fabric high concurrency sessions.
