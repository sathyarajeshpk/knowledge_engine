# Notebook export controls

Notebook Export Control is a tenant-level and workspace-level security setting that lets admins block notebook downloads and rich DataFrame export operations, closing a data exfiltration path for regulated organizations. For more information, see Notebook data export controls in Microsoft Fabric (preview).
