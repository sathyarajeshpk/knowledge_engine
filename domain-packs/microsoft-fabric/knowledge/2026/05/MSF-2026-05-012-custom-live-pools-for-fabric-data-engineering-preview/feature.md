# Custom Live Pools for Fabric Data Engineering (Preview)

Custom Live Pools for Fabric Data Engineering (Preview) let workspace and capacity admins schedule ready-to-run Spark capacity tied to an Environment item, with activation windows, lifecycle and hydration monitoring through Monitoring Hub, intentional library-publishing semantics, and support for workspaces with Managed Private Endpoints. For more information, see Configure custom live pools in Microsoft Fabric.
