# Refresh Materialized Lake View activity in Fabric Data Factory pipelines

Materialized Lake View refresh features (Preview) The Refresh Materialized Lake View activity in Fabric Data Factory pipelines in Fabric Data Factory pipelines lets you refresh materialized lake views on demand or on a schedule within your pipeline orchestration. Event-driven refresh for materialized lake views triggers dependent materialized lake view refreshes when OneLake file events or pipeline and notebook job events occur. For more information, see Schedule a materialized lake view refresh.
