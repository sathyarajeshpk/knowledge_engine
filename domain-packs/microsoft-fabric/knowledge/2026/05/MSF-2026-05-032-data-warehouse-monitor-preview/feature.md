# Data Warehouse Monitor (Preview)

Data Warehouse Monitor (Preview) (previously Query Activity) is a unified monitoring UI for Fabric Data Warehouse that shows active and historical queries side by side, supports cross-execution performance analysis powered by Query Insights, and lets you cancel long-running queries with one click. For more information, see Monitor T-SQL queries (Preview).
