# Resource Profiles in Fabric Data Engineering (Preview)

Resource Profiles in Fabric Data Engineering (Preview) are preconfigured Spark compute profiles—write-heavy, read-heavy for Spark, and read-heavy for Power BI—that you select per environment so Fabric applies workload-aware settings automatically without manual tuning of dozens of Spark properties. For more information, see Configure Resource Profile Configurations.
