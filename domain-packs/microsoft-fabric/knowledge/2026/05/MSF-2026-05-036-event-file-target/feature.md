# event_file target

MAX_ROLLOVER_FILES in extended event sessions using Azure Storage blobs (preview) For new extended event sessions, you can specify the MAX_ROLLOVER_FILES option to retain only the specified number of the most recent Azure Storage blobs. For more information, see event_file target.
