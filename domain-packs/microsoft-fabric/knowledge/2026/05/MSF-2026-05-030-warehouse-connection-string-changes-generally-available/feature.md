# Warehouse connection string changes (Generally Available)

Connection behavior changes in Fabric Data Warehouse make connections deterministic when the InitialCatalog connection string value is ambiguous or missing, improving predictability for downstream auditing. For more information, see Fabric Data Warehouse connectivity and Operation list.
