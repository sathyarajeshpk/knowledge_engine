# Workspace Identity in Apache Airflow Jobs

Workspace Identity in Fabric Airflow Jobs Workspace Identity in Apache Airflow Jobs lets you authenticate Apache Airflow jobs using workspace identity, enabling secure access to Fabric resources without managing individual credentials. For more information, see Use workspace identity to authenticate Apache Airflow Jobs to Fabric services.
