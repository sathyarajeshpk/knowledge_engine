# Excel to Delta tables with shortcut transformations (Preview)

Excel to Delta tables with shortcut transformations (Preview) extends the zero-code shortcut transformations ingestion model to multi-sheet .xlsx and .xls workbooks, with automatic sheet discovery, wildcard sheet matching, combined-table or table-per-sheet output, schema drift handling, continuous sync, and sanitization of sheet names into valid Delta table names. For more information, see Shortcuts file transformations.
