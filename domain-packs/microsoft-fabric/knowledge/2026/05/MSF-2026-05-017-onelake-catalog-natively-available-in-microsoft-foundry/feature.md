# OneLake catalog natively available in Microsoft Foundry (Generally Available)

The OneLake catalog is now natively available in Microsoft Foundry, so AI builders can browse and select OneLake data directly inside Foundry, evaluate ownership, endorsement, sensitivity, and location signals in place, and turn governed assets into knowledge sources without leaving the project. For more information, see OneLake for Microsoft Foundry.
