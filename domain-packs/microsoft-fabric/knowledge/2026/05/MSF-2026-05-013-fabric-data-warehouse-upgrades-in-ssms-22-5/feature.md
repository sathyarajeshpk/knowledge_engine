# SSMS 22.5 Fabric Data Warehouse upgrades

Fabric Data Warehouse upgrades in SSMS 22.5 SSMS 22.5 Fabric Data Warehouse upgrades add direct create, rename, and delete actions for Fabric warehouses from Object Explorer, let you generate a SQL database project from a live warehouse connection, and remove the workspace-level permission requirement so item-level permissions are sufficient to connect. For more information, see Install SQL Server Management Studio (SSMS).
