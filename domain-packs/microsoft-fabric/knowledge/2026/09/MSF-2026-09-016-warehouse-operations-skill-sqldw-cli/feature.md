# Warehouse operations skill sqldw-cli

Warehouse operations skill sqldw-cli (Generally Available) The Warehouse operations skill sqldw-cli runs bounded, read-only diagnostics for warehouse and SQL analytics endpoint issues and returns evidence, recommended actions, and validation steps. For more information, see Diagnose warehouse workloads with Warehouse operations skill sqldw-cli.
