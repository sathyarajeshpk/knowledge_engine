# Capacity Operation Events in Real-Time Hub (Preview)

Capacity Operation Events in Real-Time Hub (Preview) provide operation-level telemetry for capacity consumption, duration, throttling, workspaces, and items. For more information, see Explore Fabric capacity operation events.
