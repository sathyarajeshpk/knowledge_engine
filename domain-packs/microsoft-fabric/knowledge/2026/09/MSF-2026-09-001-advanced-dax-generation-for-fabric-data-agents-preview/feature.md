# Advanced DAX generation for Fabric data agents (Preview)

Advanced DAX generation for semantic models (Preview) Advanced DAX generation for Fabric data agents (Preview) lets a data agent plan its approach, inspect semantic model values and intermediate results, refine its reasoning, and execute a final DAX query before answering.
