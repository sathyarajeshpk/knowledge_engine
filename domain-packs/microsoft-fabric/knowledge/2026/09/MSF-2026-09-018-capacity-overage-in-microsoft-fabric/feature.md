# Capacity overage in Microsoft Fabric

Capacity overage (Generally Available) Capacity overage is now generally available for Fabric F SKUs and is enabled by default when you create a capacity. It pays for eligible excess capacity usage to help prevent throttling, up to a configurable rolling 24-hour threshold. For more information, see Capacity overage in Microsoft Fabric and Enable capacity overage in Microsoft Fabric.

Source: [fabric-whats-new](https://learn.microsoft.com/en-us/fabric/enterprise/capacity-overage-overview)
