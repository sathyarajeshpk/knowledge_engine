# private Snowflake connectivity for Fabric pipelines and Copy Jobs

Private Snowflake connectivity for pipelines and Copy Jobs To use private Snowflake connectivity for Fabric pipelines and Copy Jobs you need workspace-level private link, trusted workspace access to Azure Blob staging, and Snowflake private connectivity. For more information, see Configure Snowflake in a copy activity and Set up workspace-level Private Links.
