# Fabric Data Warehouse medallion architecture best practices

Fabric Data Warehouse medallion architecture best practices cover batch writes, rerunnable Silver transformations, consumption-focused Gold models, platform defaults, and monitoring by layer. For more information, see Fabric Data Warehouse performance guidelines and Ingest data into a warehouse.
