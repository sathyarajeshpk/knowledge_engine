# SharePoint List mirroring

SharePoint List mirroring (Generally available) SharePoint List mirroring is now generally available. You can continuously replicate SharePoint list data into OneLake and use it across Fabric workloads. For more information, see SharePoint List mirroring.

Source: [fabric-whats-new](https://learn.microsoft.com/en-us/fabric/mirroring/sharepoint-list)
