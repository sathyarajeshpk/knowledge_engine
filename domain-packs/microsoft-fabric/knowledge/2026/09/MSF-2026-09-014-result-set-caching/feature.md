# Result set caching

Result set caching works by persisting the final result sets for applicable SELECT T-SQL queries, bypassing complex compilation and data processing of the original query to return queries faster. To learn more, review the preview announcement at Result Set Caching for Microsoft Fabric Data Warehouse. Result set caching is enabled by default.

Source: [fabric-whats-new](https://learn.microsoft.com/en-us/fabric/data-warehouse/result-set-caching)
