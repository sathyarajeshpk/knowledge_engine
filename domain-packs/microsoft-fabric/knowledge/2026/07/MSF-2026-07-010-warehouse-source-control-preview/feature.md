# Warehouse source control (Preview)

By using Source control with Warehouse (preview), you can manage development and deployment of versioned warehouse objects. Use the SQL Database Projects extension available inside Visual Studio Code. For more information on warehouse source control, see CI/CD with Warehouses in Microsoft Fabric.

Source: [fabric-whats-new-markdown](https://learn.microsoft.com/en-us/fabric/data-warehouse/development-deployment)
