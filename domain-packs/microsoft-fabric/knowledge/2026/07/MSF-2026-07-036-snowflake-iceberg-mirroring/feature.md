# Snowflake Iceberg mirroring

Snowflake Iceberg mirroring syncs Snowflake Iceberg table metadata into OneLake through shortcuts so you query the data across Fabric without duplicating files. For more information, see OneLake, the unified data lake and OneLake shortcuts.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Bring-your-Snowflake-Iceberg-tables-to-OneLake-with-Fabric/ba-p/5301177)
