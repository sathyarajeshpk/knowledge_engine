# Operations Agent for Pipelines (Preview)

Operations Agent for Pipelines is an AI-powered monitoring agent that continuously watches your pipeline runs and proactively notifies you through Microsoft Teams when failures or anomalies occur. Configure the agent to monitor specific scenarios such as all pipeline failures or runs exceeding expected durations. For more information, see Operations Agent for Pipelines (preview).
