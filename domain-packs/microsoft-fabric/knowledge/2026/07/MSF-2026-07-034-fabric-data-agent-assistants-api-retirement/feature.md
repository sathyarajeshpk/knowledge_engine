# Fabric data agent Assistants API retirement

Fabric data agent Assistants API retirement requires you to migrate direct Assistants API integrations to the data agent MCP endpoint before August 26, 2026. For more information, see Use the Fabric data agent programmatically and Fabric data agent SDK.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Prepare-your-Fabric-Data-Agent-integrations-for-Assistants-API/ba-p/5314634)
