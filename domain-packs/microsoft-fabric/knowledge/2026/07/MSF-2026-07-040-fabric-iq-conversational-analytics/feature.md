# Fabric IQ conversational analytics

Fabric IQ conversational analytics lets you ask questions over governed Power BI semantic models in Microsoft 365 Copilot Chat and Copilot Cowork, and use data agents for specialized analysis. For more information, see What is Fabric IQ? and Fabric IQ in Microsoft 365 Copilot Chat.
