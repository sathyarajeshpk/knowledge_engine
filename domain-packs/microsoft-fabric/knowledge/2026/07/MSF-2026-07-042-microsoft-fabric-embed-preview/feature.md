# Microsoft Fabric Embed (Preview)

Microsoft Fabric Embed (Preview) lets you embed Real-Time Dashboards in JavaScript or TypeScript apps with delegated Microsoft Entra access. For more information, see Power BI embedded analytics and What is Microsoft Fabric Embed in Microsoft Fabric (Preview)?.
