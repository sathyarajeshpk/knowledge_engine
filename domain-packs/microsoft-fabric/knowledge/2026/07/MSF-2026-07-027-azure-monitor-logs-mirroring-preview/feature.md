# Azure Monitor Logs mirroring (Preview)

Azure Monitor Logs mirroring (Preview) brings Log Analytics workspace telemetry into OneLake so you can combine observability and business data in Eventhouse, Real-Time Dashboards, and Operations Agent workflows.
