# Autoscaling for Virtual Network Data Gateway (Preview)

Autoscaling for Virtual Network Data Gateway (Preview) automatically adjusts the number of active gateway nodes within admin-defined minimum and maximum limits based on workload demand, so the gateway absorbs spikes without manual intervention and scales down to reduce cost during idle periods. For more information, see Download logs on the virtual network data gateway.
