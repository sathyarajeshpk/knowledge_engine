# Real-time game-day operations with Eventstreams, Spark, and AI functions

Row-to-intelligent-action with DeltaFlow and AI functions Real-time game-day operations with Eventstreams, Spark, and AI functions walks through a stadium operations scenario that captures database changes with a CDC source, reshapes them with DeltaFlow (Preview), and uses AI functions in a Spark Structured Streaming notebook to classify each request by meaning and route actionable items to the right team in seconds. For more information, see DeltaFlow output transformation (preview).
