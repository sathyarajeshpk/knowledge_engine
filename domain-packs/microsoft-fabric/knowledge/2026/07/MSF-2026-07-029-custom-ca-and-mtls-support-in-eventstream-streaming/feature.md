# Custom CA and mTLS support in Eventstream streaming connectors

Custom CA and mTLS in Eventstream connectors (Generally Available) Custom CA and mTLS support in Eventstream streaming connectors lets you use custom CA and client certificates from Azure Key Vault with the MQTT, Apache Kafka, AWS MSK, and Confluent Cloud for Apache Kafka source connectors. For more information, see Add and manage eventstream sources.
