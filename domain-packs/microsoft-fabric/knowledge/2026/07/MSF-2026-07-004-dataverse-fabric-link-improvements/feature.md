# Dataverse Fabric Link

Dataverse Fabric Link improvements Dataverse Fabric Link now lets admins choose which Dataverse and finance and operations tables sync to Fabric, adds Workspace Identity and Service Principal authentication, and reduces sync latency to under 15 minutes for most cases. For more information, see Link to Fabric and Create a Dataverse shortcut.
