# OneLake security improvements

OneLake security improvements extend security to Eventhouse, make Graph integration and OneLake security APIs, simplify column-level security, and set user identity mode for SQL analytics endpoint sync. For more information, see OneLake security for SQL analytics endpoints and OneLake data access security REST API.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/New-OneLake-security-improvements-for-Microsoft-Fabric/ba-p/5314377)
