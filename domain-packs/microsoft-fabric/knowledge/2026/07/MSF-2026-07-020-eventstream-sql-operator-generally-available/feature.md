# The Eventstream SQL operator (Generally Available)

Eventstream SQL operator (Generally Available) The Eventstream SQL operator (Generally Available) lets you filter, aggregate, window, and route events with SQL, and adds multi-destination fan-out, event-time processing for late or out-of-order events, and built-in per-branch testing before you publish. For more information, see Process events by using a SQL operator.
