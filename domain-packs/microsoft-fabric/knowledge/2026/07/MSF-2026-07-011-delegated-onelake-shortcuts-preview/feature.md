# Delegated OneLake Shortcuts (Preview)

Delegated OneLake Shortcuts (Preview) let you attach an organizational account, service principal, or workspace identity to a OneLake shortcut so downstream users access the target through the delegated identity. The same model works across Microsoft Fabric tenants for parent-subsidiary and test-to-production sharing without individual cross-tenant permissions. For more information, see OneLake shortcuts and Create a OneLake shortcut.
