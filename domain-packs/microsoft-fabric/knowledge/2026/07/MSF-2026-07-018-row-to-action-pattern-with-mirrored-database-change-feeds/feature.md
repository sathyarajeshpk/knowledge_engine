# Turning Mirrored Database change feeds into real-time action

Row-to-action pattern with Mirrored Database change feeds Turning Mirrored Database change feeds into real-time action walks through a manufacturing quality scenario that mirrors an operational database into OneLake, streams Delta Change Data Feed changes into an Eventstream, filters and windows failed inspections with SQL operators, then routes them to Activator for alerts and to Eventhouse for live KQL dashboards. For more information, see Add Mirrored Database (Change Feed) source to an eventstream.
