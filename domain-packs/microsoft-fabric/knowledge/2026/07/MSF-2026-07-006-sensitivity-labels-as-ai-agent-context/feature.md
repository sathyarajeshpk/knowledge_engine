# Using sensitivity labels to guide AI agents and skills

Sensitivity labels as AI agent context Using sensitivity labels to guide AI agents and skills shows how Microsoft Purview sensitivity labels—already used for access control and protection policies in Fabric—also give AI agents organizational context to select and prioritize data by label, so agents provide fuller analysis on General data while restricting or summarizing Confidential and Highly Confidential content according to your rules. For more information, see Apply sensitivity labels to Fabric items and Information protection in Microsoft Fabric.
