# Lakehouse Query Explorer

Lakehouse Query Explorer (Generally Available) Lakehouse Query Explorer lets you run Spark SQL in the Lakehouse explorer to inspect data, test joins, create views, and iterate before you move logic to notebooks or SQL analytics endpoints. For more information, see Query data with the Lakehouse query explorer.
