# Fabric data agents in Microsoft Foundry

Fabric data agents in Foundry Fabric data agents in Microsoft Foundry now connect through MCP, appear in OneLake Catalog discovery, support multiple data agents per Foundry agent, and expose logs and traces through Foundry Observability. For more information, see Observability for Fabric data agents in Microsoft Foundry.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Fabric-data-agents-in-Microsoft-Foundry-Easier-to-connect-easier/ba-p/5318989)
