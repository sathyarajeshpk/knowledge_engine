# Customer-managed keys for Spark jobs

Spark job customer-managed keys Customer-managed keys for Spark jobs encrypt temporary local disk and shuffle data with your key so you control Spark processing-layer protection without changing jobs. For more information, see Customer-managed keys for Fabric workspaces.
