# Change event streaming overview

Change event streaming (Preview) Change event streaming (CES) captures row-level DML changes (inserts, updates, and deletes) and publishes each change to Fabric Eventstream or Azure Event Hubs in near real time as a CloudEvent, enabling downstream analytics and event-driven architectures with no ETL. For more information, see Change event streaming overview.

Source: [fabric-whats-new](https://learn.microsoft.com/en-us/sql/relational-databases/track-changes/change-event-streaming/overview?preserve-view=true&view=fabric-sqldb)
