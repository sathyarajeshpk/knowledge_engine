# Resource Instance Rules for OneLake

Resource Instance Rules for OneLake Network Security for Azure Services (Generally Available) Resource Instance Rules for OneLake let you allow specific Azure resource instances to access OneLake over the public endpoint while Fabric still evaluates data permissions. For more information, see Resource Instance rules for Inbound access.
