# Secure zero-copy distribution with OneLake security and shortcuts

Zero-copy distribution patterns with OneLake security and shortcuts explains how passthrough shortcuts evaluate permissions on the target for source-managed authorization, and how delegated shortcuts—including delegated OneLake shortcuts—use an intermediate identity so central teams delegate access management at scale and share data across Fabric tenants, with security combined via intersection. For more information, see OneLake security access control model and Secure and manage OneLake shortcuts.
