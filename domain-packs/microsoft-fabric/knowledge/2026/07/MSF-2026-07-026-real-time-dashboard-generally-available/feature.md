# Real-Time Dashboard (Generally Available)

Real-Time Dashboard (Generally Available) lets you monitor Eventhouse data with live refresh, Copilot-created tiles, drill-down exploration, Activator alerts, and team sharing. For more information, see What is Real-Time Dashboard? and Create a Real-Time Dashboard.
