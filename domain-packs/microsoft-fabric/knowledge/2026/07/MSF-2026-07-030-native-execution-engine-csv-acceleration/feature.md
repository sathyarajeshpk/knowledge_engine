# Native Execution Engine CSV acceleration

Native Execution Engine CSV acceleration reads CSV files in the native vectorized pipeline when Native Execution Engine is enabled, so existing Spark notebooks, pipelines, and SQL queries can run faster with no code changes. For more information, see Native execution engine for Fabric Data Engineering.
