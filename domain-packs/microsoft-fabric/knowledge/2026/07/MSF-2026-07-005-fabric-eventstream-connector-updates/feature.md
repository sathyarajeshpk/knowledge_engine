# Fabric Eventstream connectors

Fabric Eventstream connector updates Fabric Eventstream connectors mark private network (vNet/On-Prem) support, the Apache Kafka and Azure Service Bus source connectors, and custom CA and mTLS support across MQTT, Apache Kafka, AWS MSK, and Confluent Cloud for Apache Kafka as Generally Available, and introduce Preview support for enhanced IoT Hub connector metadata, an Oracle Database change data capture (CDC) source, and HTTP connector pagination. For more information, see Add and manage an event source in an eventstream.
