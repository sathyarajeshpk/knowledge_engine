# Native Execution Engine optimizations

Native Execution Engine optimizations reuse broadcast joins, keep ranking functions in native execution, and materialize repeated CTEs automatically so you shorten Spark query runtimes with no code changes. For more information, see Runtime 1.3 in Fabric and Native execution engine for Fabric Data Engineering.
