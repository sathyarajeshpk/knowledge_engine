# New Fabric Data Factory pipeline enhancements

Pipeline authoring and monitoring enhancements New Fabric Data Factory pipeline enhancements auto-populate base parameters for the Notebook activity and add activity-level (L2) workspace monitoring (Preview), so you drill from a pipeline run into individual failed activities for root-cause analysis. For more information, see Transform data by running a notebook and Enable workspace monitoring in Microsoft Fabric.
