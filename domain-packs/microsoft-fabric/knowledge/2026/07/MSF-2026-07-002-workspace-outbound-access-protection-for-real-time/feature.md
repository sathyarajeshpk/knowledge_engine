# Workspace outbound access protection for Real-Time Intelligence (Preview)

Workspace outbound access protection (OAP) for Real-Time Intelligence (Preview) extends workspace-level outbound network controls to Eventstream, Eventhouse, KQL QuerySet, Activator, Real-Time Dashboards, and Azure and Fabric events, so admins block unwanted outbound connections by default and allow only approved destinations through data connection rules. For more information, see Workspace outbound access protection.
