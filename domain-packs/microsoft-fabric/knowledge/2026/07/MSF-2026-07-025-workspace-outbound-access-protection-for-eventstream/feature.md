# Workspace Outbound Access Protection for Eventstream

Outbound access protection for Eventstream Workspace Outbound Access Protection for Eventstream lets you govern Eventstream sources and destinations with workspace-level data connection rules. For more information, see Workspace Outbound Access Protection overview and Set up workspace outbound access protection.
