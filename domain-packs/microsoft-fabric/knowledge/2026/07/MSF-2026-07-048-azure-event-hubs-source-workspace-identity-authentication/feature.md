# Azure Event Hubs source workspace identity authentication

Azure Event Hubs source workspace identity authentication (Preview) Azure Event Hubs source workspace identity authentication lets an Eventstream Azure Event Hubs source use workspace identity instead of shared access keys for Microsoft Entra ID-based access. For more information, see Add an Azure Event Hubs source to an eventstream.
