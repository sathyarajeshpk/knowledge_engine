# Benchmarking GPU-accelerated Fabric Data Warehouse

Benchmarking GPU-accelerated Fabric Data Warehouse shares a TPC-H benchmark at 100 GB scale factor on a Fabric F64 Trial capacity that compares CPU and GPU query acceleration across single-user and high-concurrency workloads up to 1,000 concurrent users, and reports roughly 6x throughput and 6–7x lower p95 latency on GPU with query acceleration enabled from workspace settings.
