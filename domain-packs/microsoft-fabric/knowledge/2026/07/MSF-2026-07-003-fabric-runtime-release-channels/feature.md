# Fabric Runtime Release Channels

Fabric Runtime Release Channels give each Spark runtime a Default and Early Access channel, so you preview library upgrades, dependency changes, security patches, and operating system updates on your workloads before they roll out as the new default. You opt in by setting two Spark configuration properties on your Environment. For more information, see Fabric runtime release channels (Preview).
