# configure the dropped item retention period in the Item Recovery tenant setting

Dropped warehouse recovery (Generally Available) Workspace Administrators can restore accidentally dropped warehouses from the Workspace Recycle Bin within a configurable retention window (7 to 90 days), recovering table schemas, data, snapshots, permissions, views, and stored procedures. You can configure the dropped item retention period in the Item Recovery tenant setting.

Source: [fabric-whats-new](https://learn.microsoft.com/en-us/fabric/admin/item-recovery)
