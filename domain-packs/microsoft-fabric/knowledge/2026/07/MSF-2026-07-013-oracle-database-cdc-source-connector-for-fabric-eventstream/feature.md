# The Oracle Database CDC source connector for Eventstream (Preview)

Oracle Database CDC source connector for Fabric Eventstream (Preview) The Oracle Database CDC source connector for Eventstream (Preview) streams changes from an Oracle database into Fabric as a structured change event with before and after values, using Oracle LogMiner for on-premises or cloud databases running Oracle 12c and later. For more information, see Add Oracle Database CDC source to an eventstream (preview).
