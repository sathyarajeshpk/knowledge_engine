# OneLake item-size reporting

OneLake item-size reporting (Generally Available) OneLake item-size reporting gives you a workspace storage report that breaks down item data, system data, soft-deleted data, and billing status in the Fabric portal. For more information, see Get the size of OneLake items.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Understand-your-data-with-the-OneLake-storage-report-Generally/ba-p/5295144)
