# Fabric data engineering agent (Project Osmos)

Fabric data engineering agent (Project Osmos) (Preview) Fabric data engineering agent (Project Osmos) runs persistent, Fabric-hosted tasks that autonomously plan, execute, and validate data engineering work against authorized lakehouse resources. Start tasks from a supported command-line client, review operational settings, and monitor progress and results in Fabric.

Source: [fabric-whats-new](https://learn.microsoft.com/en-us/fabric/data-engineering/data-engineering-agent-overview)
