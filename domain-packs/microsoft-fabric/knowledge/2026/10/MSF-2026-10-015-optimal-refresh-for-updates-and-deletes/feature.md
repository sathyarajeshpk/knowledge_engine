# Optimal refresh for updates and deletes

Optimal refresh for materialized lake view updates and deletes (Preview) Optimal refresh for updates and deletes lets materialized lake views process changed and deleted source rows incrementally. Refresh hints identify unique rows so Fabric can avoid a full refresh when supported source data changes.

Source: [fabric-whats-new](https://learn.microsoft.com/en-us/fabric/data-engineering/materialized-lake-views/optimal-refresh-handling-deletes-updates)
