# On-premises data gateway soft delete (Preview)

On-premises data gateway soft delete (Preview) retains supported standard mode gateways for 30 days by default so tenant and gateway admins can recover accidental deletions. For more information, see Gateway soft delete.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Soft-delete-for-On-premises-data-gateways-in-Microsoft-Fabric/ba-p/5365712)
