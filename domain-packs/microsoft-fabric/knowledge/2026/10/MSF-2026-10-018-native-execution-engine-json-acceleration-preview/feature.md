# Native Execution Engine JSON acceleration (Preview)

Native Execution Engine JSON acceleration (Preview) reads and parses JSON through the vectorized native path so supported Spark transformations can stay columnar without code changes. For more information, see Native execution engine for Fabric Data Engineering and Apache Spark runtime in Fabric.
