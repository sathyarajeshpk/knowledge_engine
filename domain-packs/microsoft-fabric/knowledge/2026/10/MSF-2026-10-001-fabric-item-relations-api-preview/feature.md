# Fabric item relations API (Preview)

Fabric item relations API (Preview) returns upstream and downstream item dependencies, typed relation edges, and related workspaces for impact analysis, catalogs, CI/CD checks, and AI agents. For more information, see Fabric REST API reference.

Source: [fabric-whats-new](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Lineage-aware-AI-with-the-Fabric-item-relations-API-Preview/ba-p/5366064)
