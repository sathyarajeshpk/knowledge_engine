# AI-assisted Synapse to Fabric migration skills (Preview)

AI-assisted Synapse to Fabric migration skills (Preview) move Synapse Spark pools, lake databases, notebooks, Spark job definitions, and Data Factory pipelines to Microsoft Fabric from the command line by using REST APIs, with lift-and-shift and migrate-and-modernize paths and a read-only assessment step. For more information, see Skills for Microsoft Fabric.
