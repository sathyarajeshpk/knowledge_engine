# OneLake Catalog table discovery (Preview)

OneLake Catalog table discovery (Preview) lets you find tables from semantic models, lakehouses, and mirrored databases by table name, description, or exact column name in global search and the Search API. For more information, see OneLake Catalog Search API and Fabric Core remote MCP server.
