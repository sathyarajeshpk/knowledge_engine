# Cosmos DB in Microsoft Fabric

Cosmos DB in Microsoft Fabric (GA) Cosmos DB in Microsoft Fabric is now generally available to all users. Since its announcement at Microsoft Build 2025, Microsoft added several new capabilities, including vector indexing and search. For more information, see Announcing Cosmos DB in Microsoft Fabric. To get started, see Quickstart: Create a Cosmos DB database in Microsoft Fabric.
